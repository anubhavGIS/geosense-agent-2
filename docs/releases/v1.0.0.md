# GeoSense Agent 2.0 — v1.0.0

The first complete release: all five phases of the project, deployed and documented.

**Try it:** [live demo](https://geosense-agent.streamlit.app) ·
[3D digital twin](https://anubhavgis.github.io/geosense-agent-2/) ·
[API docs](https://geosense-backend-917306622260.us-central1.run.app/docs) ·
[3-minute walkthrough video](https://youtu.be/Ovwtpb2bGgA)

## What is in it

- **Phase 1 — site suitability:** PostGIS with OpenStreetMap roads and hospitals, a 1,125-point
  candidate grid over Kolkata, Random Forest and XGBoost classifiers, SHAP explanations,
  `site_scorer.py`.
- **Phase 2 — satellite deep learning:** Sentinel-2 composites of 2018 and 2023 from Earth Engine,
  a U-Net land-cover model (87.2 % pixel accuracy on held-out chips), a fine-tuned Prithvi-100M for
  comparison, NDVI/NDWI and change detection in `image_classifier.py`.
- **Phase 3 — LiDAR and street level:** a PDAL pipeline for USGS 3DEP point clouds, building heights,
  canopy and impervious surface in `lidar_analyzer.py`, SAM rooftops, SegFormer street scenes and
  walkability in `streetview_semantic.py`, one unified site profile.
- **Phase 4 — agent and twin:** a FastAPI + MCP server with seven tools, a LangGraph agent with
  memory and a configurable language model, a CesiumJS digital twin with flood zones, extruded
  LiDAR buildings, four Sentinel-2 years and fly-to, and a Streamlit demo app.
- **Phase 5 — cloud and portfolio:** Docker images and Docker Compose, the backend on Google Cloud
  Run with PostGIS on Neon, the twin on GitHub Pages, the app on Streamlit Community Cloud,
  GitHub Actions that test every push and deploy it, a load test, a rewritten README, an
  architecture diagram, a demo video and a three-part article series.

## Quality

- 41 pytest tests; the 13 that need neither the laptop's data nor a running server run on every push.
- Load test against Cloud Run: 20 sequential requests, 0 errors, average 3.44 s.

## Notes

- The backend scales to zero: the first request after a quiet spell takes about a minute.
- Data, trained models and the database dump are not in the repository; the scripts of each phase
  regenerate them (see `docs/project_phases.md`). Licence: MIT for the code; the data keep their own
  licences (README, "Licence and data").
